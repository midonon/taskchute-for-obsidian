# TaskChute Plus — midonon Fork

[English](./README.md)

このリポジトリは、[Hiroya IizukaさんのTaskChute Plus](https://github.com/hiroyaiizuka/taskchute-for-obsidian)を、自分の使い方に合わせて改造したForkです。タスクの見積時間と時間帯ごとの容量を表示し、平日・休日などで時間帯の区切り方を変えられるようにしています。

TaskChute Plusの基本的な使い方、コマンド、公式版の導入については、[本家リポジトリ](https://github.com/hiroyaiizuka/taskchute-for-obsidian)と[公式ドキュメント](https://obsidian.levers.co.jp/ja/)を参照してください。ここでは、このForkで追加・変更した内容を紹介します。

## 主な変更点

### 見積時間とセクション容量

- 新規タスク作成時に見積時間を入力できます。通常のタスクとルーチンタスクに対応しています。
- タスク行の見積テキストをクリック・タップして、その場で編集画面を開けます。未設定の場合も「見積 -」から入力できます。
- 完了タスクでは「見積 30m」「実績 60m」のように、見積と実績を並べて表示します。
- 時間帯セクションのヘッダーに、所属タスクの見積合計とセクション容量、使用率バーを表示します。容量に達すると警告色、超えると赤色になります。

たとえば `60/240m` は、240分の時間帯に合計60分の見積が入っている状態です。「時間指定なし」のセクションには時間枠がないため、容量との比較は表示しません。

### 複数のセクション設定と曜日割り当て

- 平日用・休日用など、時間帯の区切り方を複数保存できます。2種類に限らず追加できます。
- 各時間帯に「睡眠」「午前」「夕食後」などの名前を付けられます。開始時刻と名前は、表形式の別々の入力欄で編集します。
- 月〜金は平日用、土日は休日用、というように曜日ごとに設定を割り当てられます。
- 特定の日だけ別の設定を使いたい場合は、タスク一覧から表示日に適用できます。

祝日を自動判定する機能はありません。祝日などの例外は、その日の設定を手動で切り替えます。

### 表示・操作の調整

開始・終了時刻、見積、実績の列を揃え、見積はクリックできるテキストにしました。タスク追加ボタンはセクション選択の隣に置き、コメント・ルーチン・設定ボタンは同じ大きさの正方形に揃えています。追加機能は日本語・英語のUIに対応しています。

## 追加機能の使い方

### 見積時間

新規タスク作成時に入力するか、タスク行の見積テキストを選択します。歯車メニューからの編集もできます。単位は分で、1以上の整数を入力します。空欄で保存すると見積時間を削除します。

見積はタスクノートのfrontmatterに保存されます。

```yaml
estimatedMinutes: 30
```

### セクション設定

1. Obsidianの設定 → TaskChute Plus → 詳細設定 → セクションを開きます。
2. 「セクション設定を管理」で、平日用・休日用などの名前、開始時刻、時間帯の名前を編集して保存します。
3. 「曜日ごとの設定」で、各曜日に使う保存済み設定を選びます。

開始時刻には0:00を含め、2つ以上の時刻を指定します。時間帯の名前は省略できます。

曜日割り当ては、今日以降でまだ日別のセクション設定がない日に適用されます。一度適用された日には、そのときの区切り方と名前が保存されます。保存済み設定や曜日割り当てを変更しても、すでに適用済みの日や過去の日は一括で書き換わりません。

その日の区切り方を変更するときは、タスク一覧のセクション選択ボタンから設定を選び、「表示日に適用」を押してください。「設定を保存」だけでは、適用済みの日の表示は変わりません。

## このForkを試す

`main` が、見積時間とセクション機能の両方を含む全部入り版です。本家のコミュニティプラグインをインストールするだけでは、このForkの追加機能は入りません。

### ソースからビルド

Node.js 22.22.1以上とnpmが必要です。

```bash
git clone --branch main https://github.com/midonon/taskchute-for-obsidian.git
cd taskchute-for-obsidian
npm install
npm run build
```

保管庫をバックアップし、まずはテスト用保管庫で試してください。TaskChute Plusを無効にしてから、ビルドした `main.js`、`manifest.json`、`styles.css` の3ファイルを、保管庫内の `.obsidian/plugins/taskchute-plus/` に配置し、再び有効にします。

本家と同じプラグインIDを使うため、同じ保管庫では本家版の差し替えになります。既存の `data.json` やタスク・ログを削除したり、別の保管庫の設定で上書きしたりしないでください。本家版へ更新すると、プラグイン本体が本家版に置き換わり、このForkの追加機能は使えなくなります。

GitHub Releaseから導入する場合も、そのReleaseに必要な追加機能が含まれていることを確認し、同じ3ファイルを使ってください。
